## Project Overview

This project is an advanced responsive personal portfolio developed using HTML5, CSS3 and JavaScript.

The main purpose of the project is to demonstrate advanced CSS concepts including CSS Grid, Flexbox, CSS variables, animations, transitions, advanced selectors and BEM methodology.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- CSS Variables
- CSS Animations
- Responsive Design
- BEM Naming Convention
- LocalStorage

## Main Features

- Responsive navigation
- Hero section
- About section
- Skills grid
- Project gallery
- Contact form
- Dark and light theme
- LocalStorage theme persistence
- CSS Grid layouts
- Flexbox layouts
- Hover effects
- CSS animations
- Focus effects
- Mobile responsive design
